Azure Identity & Governance Lab

Azure identity-management exercises focused on limiting permissions and maintaining visibility into cloud spending.

Project overview

Objective

Practice the fundamentals of Microsoft Azure identity, authorization scopes, and cost visibility in a controlled lab environment.

Architecture and technologies

  • Microsoft Entra ID user accounts and security groups.
  • Azure resource groups used as assignment scopes.
  • Azure Role-Based Access Control (RBAC) to practice least privilege.
  • Azure Cost Management budget with threshold alerts at 50%, 80%, and 100%.

What I worked on

Provisioned role-specific identities, grouped users, and assigned RBAC roles to support access control at the resource-group scope. Configured budget notifications to make spending visible while learning the Azure management model.

Important distinction: Azure budgets and alerts notify when thresholds are reached; they do not, by themselves, hard-stop resource spending.

Access-control approach

I organized role-specific Entra ID identities into security groups and practiced assigning Azure RBAC roles at the resource-group scope. Assigning permissions at a defined scope supports least privilege and makes access more straightforward to review.

Cost governance

I configured a subscription-level monthly budget and alert thresholds at 50%, 80%, and 100%. These alerts improve visibility into spending but do not automatically prevent additional charges.
