Active Directory Home Lab

Designed and deployed a two-VM Windows domain using Hyper-V, then expanded it with user and group administration, Group Policy, shared drives, and remote management. Each stage below is supported by screenshots from the original lab repository.

Project overview

Purpose

Build a realistic Windows domain lab and practice administrative workflows used in IT support and junior systems administration: deploying a domain controller, joining a workstation, managing users, applying policies, controlling access to shared resources, and troubleshooting client issues.

Architecture

  • Host: Windows 11 Pro running Microsoft Hyper-V with an isolated internal switch named LabNetwork.
  • DC01 — 192.168.10.10: Windows Server 2022 Standard acting as the lab.local domain controller and DNS server.
  • WS01 — 192.168.10.20: Windows 11 Enterprise workstation joined to lab.local.

What I implemented

  • Installed Active Directory Domain Services and configured DNS for domain operations.
  • Created IT, HR, Finance, and Management OUs; provisioned five domain users and security groups.
  • Performed help-desk tasks including password resets, account disabling, and group membership changes.
  • Configured Lock-Screen, Disable-USB-Storage, and Corporate-Wallpaper GPOs; validated results with gpupdate and gpresult.
  • Created IT, HR, and AllStaff shared folders and mapped department drives with Group Policy Preferences and group-based item-level targeting.
  • Configured and tested a Remote Desktop session from DC01 to WS01.

Troubleshooting examples

  • Domain join failed: Diagnosed DNS resolution failures between VMs; restarted the DNS service, corrected firewall handling, and verified resolution before joining the domain.
  • GPO verification returned Access Denied: Re-ran computer-scope gpresult in an elevated command prompt.
  • Mapped drives were missing: Corrected security-group membership and signed out and back in so targeted drives appeared.
  • Password reset rejected: Consulted the Default Domain Policy and supplied a password meeting complexity requirements.

Next planned improvement

Automated bulk account provisioning from a CSV using PowerShell. This is listed as pending in the lab repository, not as completed work.
