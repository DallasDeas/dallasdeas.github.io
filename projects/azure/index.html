Azure Identity & Governance Lab

An Azure lab focused on Microsoft Entra ID, group-based RBAC at resource-group scope, and subscription cost monitoring. Seven annotated screenshots and an accompanying recorded walkthrough document the configuration.

Project overview

Objective

Set up an Azure learning environment that separates user accounts by function, organizes them into security groups, assigns selected roles at the resource-group level, and provides visibility into cloud spending.

What I configured

  • Microsoft Entra ID: Four lab identities for the main account, lab administration, VM operations, and read-only audit use.
  • Security groups: g-cloud-admins, g-vm-ops, and g-audit-readonly with assigned membership.
  • Scope: The dd-lab-core resource group used as a boundary for specific role assignments.
  • Azure RBAC: Reader and Virtual Machine Contributor roles assigned to function-specific groups at the resource-group scope.
  • Budget: A $25 monthly subscription budget with notifications at 50%, 80%, and 100%.

Access-control interpretation

The IAM view shows g-audit-readonly assigned Reader and g-vm-ops assigned Virtual Machine Contributor at dd-lab-core. Assigning roles at a resource-group scope is more constrained than granting the same roles to the whole subscription. The screenshot also shows two subscription-level Owner assignments inherited into the resource group, so the environment is not a demonstration that all access is least-privileged.

Cost governance and its limit

Azure Cost Management alerts can warn when spend reaches a threshold; a $25 budget is a visibility tool, not a hard stop. The lab screenshot shows the 50%, 80%, and 100% thresholds configured; it does not prove what would happen after an alert triggers.

What remains to verify

A follow-up permissions test should sign in as the audit and VM operations identities to demonstrate actual allowed and denied operations. These tests are not shown in the supplied screenshots, so they are not claimed here.

Screenshots are cropped and identifiers redacted for public sharing. The original MP4 is not published because it can disclose account details.
