Active Directory Home Lab

A virtualized Windows domain environment built in Hyper-V to practice identity administration, domain join, DNS, and troubleshooting.

Project overview

Objective

Deploy a Windows Server-based domain controller and domain-joined workstation to learn core Active Directory administration and diagnose deployment problems.

Architecture and technologies

  • Microsoft Hyper-V virtualization host with an isolated internal virtual network.
  • Windows Server 2022 virtual machine running AD DS and DNS.
  • Windows 11 client joined to the domain.
  • Static addressing and DNS configuration for domain functionality.
  • Organizational units, domain users, and security groups for access-management practice.

What I worked on

Installed and configured a domain controller, connected a Windows 11 endpoint, and practiced creating and managing domain identities. Resolved environment issues involving Secure Boot, TPM compatibility, and DNS resolution between virtual machines.
