Enterprise Network Infrastructure

Cisco Packet Tracer lab covering segmented enterprise LAN connectivity, dynamic routing, controlled inter-VLAN access, and secure device management.

Project overview

Objective

Design and configure a two-tier enterprise LAN that supports multiple VLANs, scalable routing, managed internet access, and controlled traffic between network segments.

Architecture and technologies

  • Four VLANs with 802.1Q trunking and Layer 3 inter-VLAN routing.
  • EtherChannel / LACP for aggregated switch links.
  • OSPF for dynamic routing between Cisco devices.
  • Centralized DHCP with ip helper-address relay.
  • NAT/PAT to translate RFC 1918 private addresses.
  • Extended ACLs to restrict access to critical server resources.
  • SSHv2 and SSH-only VTY management instead of Telnet.

What I worked on

Configured Cisco IOS routing, switching, IP services, access control, and device-management security in a Packet Tracer environment. The goal was to bring multiple network functions into one coherent design rather than treat each configuration as an isolated exercise.

What this lab demonstrates

The lab combines Layer 2 segmentation, Layer 3 forwarding, routing, and policy enforcement in a two-tier Cisco topology. The value is in explaining how VLANs, trunks, OSPF, DHCP relay, and ACLs interact when troubleshooting end-to-end connectivity.
